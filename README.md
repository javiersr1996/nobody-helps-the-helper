# scbasket

Value-weighted space control for basketball, built on SkillCorner's open broadcast
tracking data for the Spanish Liga ACB 2025-2026.

Work in progress. Entry for the PySport x SkillCorner Analytics Cup 2.0.

## Getting the data

The dataset is not versioned here (about 730 MB, tracking files travel over Git LFS):

```
python scripts/fetch_data.py
```
