# Lessons

## A number with no code behind it is not a finding
**Why:** findings 4 and 5 opened the README with no code in the repo (111a9ac); rebuilt, 5
reversed and its replacement was refuted, and 4 answered a question Goldsberry never asked.
**How to apply:** name the script that prints it, RUN it, read the value back off the BUILT
artefact (video said 60 s, file 68); counts too ("8 of 10" was 7). Assert and re-read.

## The deliverable follows the claim: its nulls and its examples
**Why:** F6's cost side lived only in `todo.md`; narrowed to near help, no page drive was one.
**How to apply:** ship the qualifying negative NEXT TO the claim; when a claim narrows, re-run the
rule behind every example (hook, figures, video) inside the new class before touching any text.

## Verify what moves by driving it, not by looking at it
**Why:** clips checked with screenshots shipped nine defects, all in transitions a still cannot
show (end of a clip, resume after pause, a button's label); two flipped with the possession.
**How to apply:** assert the state machine from the console (draw, seek, end); time it alone on
the real GPU (SwiftShader or a second browser faked 3 timing failures). [[lessons-archive]].

## A check that cannot fail has checked nothing
**Why:** the drive-frame check compared `direction` with the sign of a lateral motion ALREADY
mirrored to be positive (1.000, really 0.67); the "committed" split read the man's position at
2.0 s, the very point the measure aims at, and made the -0.63 headline (helper-only: -0.19, CI 0).
**How to apply:** before trusting a 100 % or a group gap, name what would have made it vanish;
a check or a split that reads the outcome's own quantity is comparing it with itself.

## Two runs at different times are not two targets
**Why:** the URL's start-up failing where an earlier local run had passed was written up as
"same bytes, so it is the network"; run in turn, the local file failed and the URL passed.
**How to apply:** compare A and B interleaved in one sitting (A B A B), fresh browser each, and
read the spread before the difference; time a page change against its old version the same way.
